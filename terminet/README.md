# @akhileshrangani4/profile

Akhilesh Rangani's [terminet](https://www.npmjs.com/package/terminet) profile, a terminal-native profile page.

## View it

```sh
npx terminet akhileshrangani4
```

## What's here

- `profile.json` — the profile itself (name, tagline, links, accent, connections)
- `profile.schema.json` — schema `profile.json` validates against
- `AGENTS.md` — notes for a coding agent editing this profile

## Edit and publish

```sh
npx terminet preview --watch   # live preview while editing profile.json
npx terminet publish           # publish to npm as @akhileshrangani4/profile
```
